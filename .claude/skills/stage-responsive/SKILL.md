# 电脑 / 手机适配

**默认两边都适配，只做竖屏。** 详细说明在 `docs/mobile.md`。

## 断点
- 只用 `lg`（1024px）：以下手机布局，以上电脑布局。
- **移动优先**：不带前缀的类名是手机的，`lg:` 覆盖成电脑的。
  ```tsx
  <header className="h-10 px-3 text-xs lg:h-14 lg:px-6 lg:text-sm" />
  ```
- 平板（768–1023px）用手机布局，内容收成居中一列：`mx-auto w-full max-w-2xl`。
- 电脑上也别撑满超宽屏：`mx-auto max-w-6xl`。

## ★安全区（iOS 刘海、灵动岛、home 条）
工具类是 SDK 自带的（`@dianziji/stage/styles.css`），`StageBoot` 自动接收平台推的安全区，**你只管用工具类**（原理见 `docs/mobile.md`：iframe 里 `env()` 恒为 0，平台量好推进来）：

| 用法 | 什么时候 |
|---|---|
| `pt-safe` | **贴着屏幕顶部的东西**（顶栏、返回按钮）：不加，iOS 状态栏会压住它 |
| `pb-safe` | 贴着屏幕底部的东西 |
| `px-safe` | 横向贴边的东西（刘海屏横向也有缺口） |
| `pb-composer` | 底部输入条：安全区和键盘取大的那个再加 12px |
| `top-[calc(var(--safe-top)+60px)]` | 浮在顶栏下面的东西 |

- **让位的是内容不是容器**：背景铺满到屏幕边（`fixed inset-0`），只用 padding 把按钮、文字顶开。
- 浮动按钮要和顶栏放在**同一个布局容器**里（同样的 `mx-auto max-w-* px-*`），左右边缘才对得齐。

## 输入
- 整页 `fixed inset-0`，键盘弹出时页面不会被推走。
- **手机上输入一律走全屏输入层**（例子：`src/components/InputSheet.tsx`）：原地输入框会被键盘挡住或把布局挤乱。电脑上可以原地输入（`hidden lg:flex`）。
- 输入框字号 ≥ 16px（`text-base`）：iOS 小于 16px 聚焦时会放大整页。

## 放不下怎么办
- 手机竖屏放得下就放一屏；**放不下就让内容区滚动**（`overflow-y-auto overscroll-contain`），**别硬挤**：固定高度 + `overflow-hidden` 会让元素互相重叠、被截断。
- 信息多的块在手机上做成底部抽屉 / 全屏页（例子：`GameMenu` 菜单、`Pages` 里的地图 / 图册 / 记录页），别和主画面抢地方。
- 顶栏在手机上尽量紧凑（一条细胶囊），立绘是主角；次要入口收进菜单。
- 可点区域至少 40×40px。触屏没有 hover：别把重要信息只放在 hover 里。

## 验收
- 电脑：1280×800、2000 宽（真实电脑屏很宽）。
- 手机：375×667（小屏）、390×844（刘海屏）。
- 每个尺寸看：顶部有没有被状态栏压、底部有没有被 home 条压、键盘弹起时输入还看得到吗、长文本 / 空状态 / 出错状态。
