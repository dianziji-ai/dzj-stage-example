# 自检与上线

## 自检清单（全部打勾才能说「做完了」）

**命令**
- [ ] `npm test`（会先检查 `packages/` 没被改过）
- [ ] `npx tsc -b`
- [ ] `npm run lint`
- [ ] `npm run pack` 成功生成 `stage.zip`

**画面**（`npm run dev` 打开，开发者工具切设备）
- [ ] 电脑 1280×800、2000 宽
- [ ] 手机 375×667、390×844：顶部没被状态栏压、底部没被 home 条压
- [ ] 手机上点输入：全屏输入层，键盘弹起看得到输入
- [ ] 长文本、空状态（还没聊）、出错状态都看过（断网：开发者工具切离线；能量不足：看 `ErrorNotice` 的代码路径即可，**不用真把能量花光**）
- [ ] AI 正在写的时候：正文跟着流、表情 / 场景不闪半截值（**要发真实消息先问作者**：每条扣能量、写进历史）
- [ ] 没有浏览器 / 没法在网站里打开、看不到画面的：照实告诉作者哪些没看，别写「已验证」

**规矩**
- [ ] 没改 `packages/`
- [ ] 没外链别的网站的素材
- [ ] `public/` 的路径用 `BASE_URL` 拼
- [ ] 没有 `alert` / `confirm`
- [ ] 动画只动 `transform` / `opacity`，手机上没有 blur
- [ ] `src/stage.ts` 还是一行 `createStage()`；没有绕开 `stage` 自己 `fetch` 平台接口或 `postMessage`

## 上线
1. `npm run pack` → 项目根目录的 `stage.zip`（加载页底部会显示这次的构建号 `BUILD 时间戳`；告诉作者这次的 BUILD 号）。
2. 网站编辑器 →「舞台」→「③ 上线」→ 上传 `stage.zip`。**目前只有平台管理员能上传**：告诉作者把 `stage.zip` 和卡 id 发给平台管理员。
3. 网站上进入卡：新游戏 → 开场 → 舞台：**先看加载页底部的 BUILD 号是不是刚打的那个**，再玩一轮，存一次档，刷新一次。

★`stage.zip` 不进 Git（已在 `.gitignore`）。舞台没有凭证（和网站之间只有 postMessage 桥），打包产物里本来就没有要清的东西。

## 交付时告诉作者
做了什么、改了哪些文件、怎么验证的（跑了哪些命令、看了哪些尺寸）、**还有什么没做 / 没验证**。
