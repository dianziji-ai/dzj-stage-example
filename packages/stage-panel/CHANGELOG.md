# @dianziji/stage-panel

官方维护的版本记录（暂未发布 npm）。★作者开发时不要改这个包：不够用向官方提需求，官方出新版时整个替换。

## 0.1.0 — 2026-10-06

- README 使用教程（用法、参数、六个标签、全部配色变量 + 深色写法、改源码指南）。
- 测试：`test/` 和 `src/` 一一对应（45 个，jsdom + Testing Library），`npm test` 带覆盖率门槛；`test/structure.test.ts` 守着「只依赖 react 和 SDK」「每个模块都有测试」。
- 只需要客户端的地方改从 `@dianziji/stage/client` 引。

- 首个内部包版本：从脚手架 / galgame 两份「调试面板」合成一份。
- `<StagePanel stage={stage} />`：入口按钮 + 面板（第一次打开才下载面板代码）；`openStagePanel()` / `closeStagePanel()` 从游戏自己的菜单开关。
- 所有人都能看全部内容（系统内置预览）：概览（在网站打开这一局、模型、本局消耗）、初始设定、历史（原文 + 每轮消耗 + 往前翻）、图册、存档、存档结构、分区。
- 图册：和网站画廊同一套解锁（这张卡累计轮数 × 相册 rounds），锁着的不给图片地址；打开才请求，书架只出封面，相册内每页 24 张缩略图。
- 存档玩家可以自己改（JSON，后端按存档结构校验），存档结构折叠在同一页下面；保存时 `source: 'panel'`，游戏订阅 `stage.on` 跟着更新界面。
- 开发模式（开发 token 或 `dev`）多出 token 细节、消息 id、设定 key 和原文。
- 换肤：覆盖 `--color-sp-*` 主题变量（见 styles.css）。电脑居中弹窗（左侧竖排标签）、手机全屏，照顾安全区。
